# Changelog

## v1.7.0 (2026-08-12)

### Добавлено
- **Fallback-прокси** — резервный прокси (`config.json → fallback.proxy_url`), на который переключается Xray если все из балансера мертвы
- **Мульти-target healthcheck** — проверка нескольких URL (`healthcheck.targets: ["https://t.me", "https://youtube.com", ...]`)
- **Возраст процесса** — если Xray работает дольше 12 часов, монитор принудительно перезапускает его
- **Debug-режим Xray** — `xray.debug: true` включает `loglevel: debug` для отладки
- **Авто --setup после обновления** — при скачивании новой версии exe автоматически пересоздаёт задачи в планировщике
- **--status показывает возраст Xray и статус всех target_url**

### Исправлено
- Принудительное обновление `download_url` при каждой загрузке конфига (больше не зацикливается на старой версии)
- `test_config` ждёт освобождения порта перед запуском Xray
- Обработка ошибок при обновлении (access denied, base_library.zip)

---

## v1.6.0 (2026-08-11)

### Добавлено
- **Собственный пинг-тест** — перед формированием конфига TCP-пингует все прокси, сортирует по скорости
- `config.json → ping` — настройки пинга (enabled, timeout_sec, max_workers)
- В логах отображается диапазон пинга отобранных прокси
