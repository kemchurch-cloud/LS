# Changelog

## v1.5.0 (2026-08-10)

### Добавлено
- Автообновление: проверка `version.txt` на GitHub, скачивание и замена exe
- Миграция `config.json`: недостающие поля добавляются автоматически
- `--status` — показать текущий статус (порт, Xray, healthcheck, стратегия)
- `--test` — быстрая проверка healthcheck
- `--update` — принудительное обновление
- `--ignoreupdate` — запретить автообновление при запуске
- Поддержка стратегий балансировки: `leastPing` (по умолчанию) и `random`
- Observatory для `leastPing` (проверка latency прокси)
- Ротация логов: `local-socks.log` переименовывается в `.old.log` при превышении 1 МБ

### Исправлено
- Healthcheck: curl с `-s -L -o NUL` вместо `-I` (меньше ложных FAIL)
- Таймаут healthcheck увеличен до 12 секунд
- Валидация конфига Xray: логи ошибок сохраняются в `*_test.log`
- Конфиг сохраняется с расширением `_new.json` (не `.temp`)
- Откат к предыдущему конфигу при невалидном новом
- Отправка Telegram-уведомлений через SOCKS5 (если прокси жив)
- Уведомления при старте обновления и после завершения
- Информация о версии, хосте, IP в уведомлениях
- Счётчик прокси: "12/20" если был лимит

### Изменено
- `SCRIPT_DIR` определяется через `sys.executable` для exe (не временная папка)
- Стратегия по умолчанию: `leastPing`
- `config.json` расширен полями `balancer`, `update`, `observatory`
- `RepetitionDuration` убран для бесконечного повторения задач
